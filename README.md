### 💻 Projetos em destaque

#### 🛍️ DSCommerce — Java Spring

Sistema completo de comércio eletrônico desenvolvido com **Java e Spring Boot**, com áreas para clientes e administradores.

**Tecnologias:** Java • Spring Boot • Spring Data JPA • Spring Security • OAuth2 • H2  🔗 [Ver projeto](https://github.com/gabyferrari/project-dscommerce-javaspring-professional)

#### 🛒 DSCommerce — React

Frontend do projeto DSCommerce desenvolvido com **React**, criando a interface de uma aplicação de comércio eletrônico.

**Tecnologias:** React • TypeScript • HTML • CSS • Vite  🔗 [Ver projeto](https://github.com/gabyferrari/project-dscommerce-reactjs)

#### 🎓 DSCatalog — Java Spring

Sistema de catálogo de produtos desenvolvido com **Java e Spring Boot**, incluindo CRUD, autenticação e áreas de cliente e administrador.

**Tecnologias:** Java • Spring Boot • Spring Data JPA • Spring Security  🔗 [Ver projeto](https://github.com/gabyferrari/project-dscatalog-javaspring-expert)

#### 🎮 DSList

API REST desenvolvida para **listagem e organização de jogos de videogame**, utilizando Java e Spring Boot.

**Tecnologias:** Java • Spring Boot • Spring Data JPA • PostgreSQL  🔗 [Ver projeto](https://github.com/gabyferrari/project-dslist)

#### 📚 DSLearn — Java Spring

Plataforma de ensino desenvolvida com **Java e Spring Boot**, com gerenciamento de cursos, turmas, alunos e fórum de perguntas e respostas.

**Tecnologias:** Java • Spring Boot • Spring Data JPA • Spring Security  🔗 [Ver projeto](https://github.com/gabyferrari/project-dslearn-javaspring-reference)
